## 2024-08-22 - [HIGH] XSS Vulnerability in Streamlit Markdown Rendering
**Vulnerability:** Cross-Site Scripting (XSS) vulnerability found in UI components (`components/dashboard.py` and `components/threat_matrix.py`) where user-controlled log data (e.g. usernames, IPs) from `alerts` was directly interpolated into HTML strings and passed to `st.markdown(..., unsafe_allow_html=True)`.
**Learning:** In Streamlit applications, enabling `unsafe_allow_html=True` allows for rich UI components but bypasses default output encoding, exposing the application to XSS if raw data is injected. Attempting to sanitize at the data layer can mutate original data and cause bugs, so it must be done at the presentation layer.
**Prevention:** Always use `html.escape()` strictly at the UI rendering layer before interpolating raw data into HTML strings that will be passed to `st.markdown` with `unsafe_allow_html=True`. A dictionary comprehension like `{k: html.escape(str(v)) if isinstance(v, str) else v for k, v in alert.items()}` is a safe and effective pattern.
